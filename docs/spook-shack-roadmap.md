# Spook Shack MVP Roadmap

## Slice 1 — foundation
- SQLite persistence
- role-aware API gates
- encrypted source credentials
- audit logging

## Slice 2 — source registry
- seed the five requested sources
- allow admin updates
- queue ingestion runs safely

## Slice 3 — analyst workflow
- true positive / false positive notes
- recent notes and runs in the dashboard

## Slice 4 — report scaffolding
- generate draft weekly/monthly/quarterly/annual reports
- persist report runs in SQLite

## Slice 5 — next iteration
- real connectors
- normalization and correlation
- RSS ingestion
- source discovery
